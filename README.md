# Arduino Ultrasonic Servo LED Project

An Arduino-based smart distance detection system that uses an ultrasonic sensor to measure distance, control a servo motor angular position, and trigger an LED indicator.

## Project Overview
This project demonstrates how to integrate multiple hardware components with an Arduino board. The ultrasonic sensor continuously monitors the environment; when an object is detected within a threshold of 10 cm, the servo motor rotates and the LED turns on.

## Components Used
* Arduino Uno
* Ultrasonic Sensor (HC-SR04)
* Servo Motor
* LED & 220Ω Resistor
* Breadboard & Jumper Wires
